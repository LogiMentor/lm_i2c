# Security Policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub private vulnerability reporting when it is available. Otherwise,
contact LogiMentor through an official channel published on the
[LogiMentor GitHub organization](https://github.com/LogiMentor).

Include the affected revision, impact, reproduction steps, and any suggested
mitigation. Remove secrets, credentials, personal data, and unrelated
confidential material from reports.
